# Тагнуулын ширээ (Spyfall voice lobby)
Утасны PWA. Ажиллуулах: `npx serve .` (эсвэл `python3 -m http.server`) → утсаараа нээгээд "Add to Home Screen".
Микрофон HTTPS эсвэл localhost дээр л ажиллана.
- Зураг: Профайл → аватар дээр дарж өөрийн зургаа оруулна (256px болгож хадгална).
- Mic товч: ширээний доор; ярьж байвал аватар цэнхэрээр гэрэлтэнэ.
- Чат: ширээний доор. Одоогоор нэг төхөөрөмжийн tab хооронд ажиллана.
- Жинхэнэ олон хүнтэй болгох: `send()` (app.js) руу WebSocket, дуу хоолойд WebRTC (LiveKit/Agora гэх мэт) холбоно.
